Add a listing from an Etsy URL

Paste the full Etsy listing URL. We'll pull the title, price, description and photos automatically. You can edit any field before saving, and pick which photo to use.

Etsy occasionally blocks server-side fetches from datacentre IPs. If Fetch fails, click Manual entry and paste an image URL by right-clicking the photo on the Etsy listing → Copy image address.
